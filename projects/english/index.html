Pedagogical Architecture

Why these tools work: they reject passive recognition in favor of enforced cognitive retrieval and systematic error recovery.

Active Production

Recognition is not mastery. Each tool requires either direct typing or commitment before revealing the answer, breaking the illusion of competence caused by multiple-choice guessing.

Sentence Variation

When you miss an item, the error-recovery loop rotates through alternative sentences testing the identical phrase. You learn the underlying syntactic pattern, not a static flashcard.

3 · 10 · 30d Spaced Rechecks

Graduating an item to the "Fixed" list is not the end. Items return for mandatory typed rechecks at 3, 10, and 30-day intervals to verify that short-term recall has consolidated into long-term memory.

Offline-First & Client-Side

All engines run 100% locally in your browser with zero external server dependencies. Progress persists in localStorage, and error logs can be exported directly as printable 2-page PDF worksheets.
